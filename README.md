## Mejoras y funcionalidades implementadas

Se realizaron diversas mejoras en el proyecto original con el objetivo de enriquecer la experiencia de juego, mejorar las animaciones y añadir nuevas mecánicas y sistemas de control.

### 🎮 Animaciones
- **Animación del personaje:** se incorporaron animaciones para mejorar la representación visual de sus movimientos.
- **Animación de los enemigos:** se añadieron animaciones para darles mayor dinamismo durante el juego.

### ⏱️ Sistemas de tiempo y estadísticas
- **Cronómetro:** se implementó un sistema de temporizador para controlar el tiempo disponible durante el nivel.
- **Contador de enemigos eliminados:** se agregó un contador que registra la cantidad de enemigos derrotados por el jugador.

### ⚔️ Mejoras en las mecánicas de juego
- **Eliminación de enemigos por salto:** se implementó una mecánica que permite eliminar a los enemigos al saltar sobre sus cabezas, similar a la utilizada en *Super Mario Bros.*
- **Comportamiento de los enemigos:** se mejoró la inteligencia básica de los enemigos para que detecten la proximidad del jugador e intenten atacarlo.
- **Control de aparición de enemigos:** se estableció un límite máximo de tres enemigos activos simultáneamente. Cuando se elimina uno, se permite la aparición de otro, evitando que se generen enemigos de manera ilimitada.
- **Sistema de lanzamiento de cuchillas:** se limitó la cantidad de cuchillas activas a dos. Al lanzar una tercera, la primera se elimina automáticamente, evitando la acumulación ilimitada de proyectiles.

### ⭐ Sistema de coleccionables y puntuación
- **Objetos coleccionables:** se incorporó un sistema de recolección de tres objetos por nivel.
- **Sistema de clasificación por estrellas:** al completar el nivel, el jugador recibe una clasificación de hasta tres estrellas según la cantidad de coleccionables obtenidos. La cantidad de estrellas depende de su desempeño durante la partida.

### 🖥️ Interfaces y menús
- **Menú de presentación:** se añadió una pantalla inicial para presentar el juego antes de comenzar la partida.
- **Menú de controles:** se incorporó una interfaz para consultar las teclas y acciones disponibles.
- **Menú de victoria:** se implementó una pantalla que aparece al completar el nivel, mostrando el resultado obtenido.
- **Menú de derrota:** se añadió una pantalla que aparece cuando el jugador pierde, permitiendo identificar el final de la partida.

### Objetivo de las mejoras

Estas modificaciones buscan mejorar la jugabilidad, incorporar nuevas mecánicas de interacción, ofrecer información sobre el rendimiento del jugador y proporcionar una experiencia más completa mediante animaciones, interfaces y sistemas de control de los elementos del juego.
